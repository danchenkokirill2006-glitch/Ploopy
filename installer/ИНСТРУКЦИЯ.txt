# Ploopy для установки

1. Распакуй архив в любую папку.
2. Запусти «Установить Ploopy.bat».
3. Приложение установится в `%LOCALAPPDATA%\Programs\Ploopy`, появится ярлык на рабочем столе и откроется.

Горячее сочетание скачивания по умолчанию: Ctrl + Shift + J. Его можно изменить в настройках приложения.
Пакет содержит чистые начальные настройки и пустую историю загрузок. Python устанавливать не нужно.
