# Lucide SVG assets

The SVG files in `icons/` are from the official Lucide icon set and are used under its ISC license. Original sources: https://github.com/lucide-icons/lucide/tree/main/icons

The icons are rendered with the bundled `resvg_py` Windows x64 wheel into antialiased Tk-compatible images at runtime. Original vector SVG files are kept alongside the application.
