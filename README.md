# Ploopy

Ploopy скачивает видео и файлы по ссылке. Приложение работает в системном трее Windows и использует yt-dlp для поддерживаемых сайтов.

## Установка

Скачай `Ploopy-vX.Y.Z.zip` со страницы [Releases](https://github.com/danchenkokirill2006-glitch/Ploopy/releases), распакуй архив и запусти `Установить Ploopy.bat`. Установщик создаст ярлык на рабочем столе. Python устанавливать не нужно.

## Использование

- Скопируй ссылку и нажми **Ctrl + Shift + J**. Сочетание можно изменить в настройках приложения.
- Закрытие окна кнопкой X сворачивает Ploopy в трей. Чтобы завершить работу, выбери «Выход» в меню значка.
- В настройках можно включить запуск вместе с Windows, запуск в трее и звуковой сигнал.
- Поддерживаются прямые HTTP/HTTPS-ссылки и сайты, которые умеет обрабатывать yt-dlp. Доступность зависит от сайта и доступа к видео.

Приложение проверяет обновления при запуске. Если найдёт новую версию, предложит установить её; также обновление можно проверить через меню значка в трее. Настройки и история загрузок остаются на компьютере пользователя и не входят в исходный код или архив релиза.

## Выпуск обновления

1. Внеси изменения в исходный код.
2. Создай и отправь тег новой версии, например `v1.0.1`.
3. GitHub Actions соберёт Windows-пакет и опубликует его в Releases. Установленные приложения увидят новую версию при следующей проверке.

Для локальной сборки запусти `installer/Собрать пакет.ps1`. Требуется Python 3.10; сборка выполняет проверку приложения и сценариев установки.
